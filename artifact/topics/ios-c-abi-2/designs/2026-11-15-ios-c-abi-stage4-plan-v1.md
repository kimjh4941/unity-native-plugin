## 1. 決まったこと（利用者の判断、2026-11-15）

- **iOS のサンプルの画面の UI テストは、Android と同じ深さにする**。Android の `scripts/android_ui_driver.py` にあたる「手伝い役」（XCUITest がテストの依頼を待ち、システムの画面を押す）を iOS 用に作る。Player のテストはサンプルのシーンのボタンを C# から押し、アラート・共有のシート・許可のダイアログ・通知のバナーは手伝い役が押す。工数はかかるが、この方針にする
- **手の確認表を置く**（利用者の判断、2026-11-15）: 自動のテストはボタンを C# から押すので、見た目と本当のタッチは通らない。リリースの前に実機で 1 回、サンプルの画面ごとに「全部のボタンが見えて指で押せる、セーフエリア（ノッチ、ダイナミックアイランド、ホームインジケーター）に隠れない、縦と横、スクロールの端まで届く」を見る。機能の確かめ（押した結果、システムの画面の答え）は自動のテストで見る。Android と Windows にはこの確認が無い（マニュアルの撮影で触っただけ）。今回は iOS にだけ置き、ほかの 2 つは必要になったら足す
